# Russia–NATO Monitor

Автономная русскоязычная редакция Telegram-канала. Она круглосуточно отслеживает отношения России и НАТО: признаки эскалации и деэскалации, военную активность, гибридные инциденты, официальные оценки.

Проект независим от AI Newsroom (`Documents/AI_monitoring`) и telegram-ai-news. Из них переиспользованы проверенные решения: Gemini free tier, кластеризация по эмбеддингам, очередь Telegram с честной обработкой неоднозначных отправок. Разбор того, что взято, что изменено и почему, — в [docs/PLAN.md](docs/PLAN.md).

## Как это работает

```
~100 источников (RSS, официальные сайты, Telegram-каналы, GDELT)
 → дедуп URL/заголовков, проверка дат, многоязычный ключевой фильтр      (бесплатно)
 → AI-триаж пакетами по 25: релевантность, категория, FACT/CLAIM, сигнал  (Gemini)
 → эмбеддинги → события (одно событие = много статей на разных языках)
 → переход по ссылкам к первоисточнику (официальный сайт / агентство)
 → редакционный анализ: русский текст, утверждения FACT/OFFICIAL_CLAIM/…,
   новизна, контрсигналы, факторы важности
 → importance 0–100 (объяснимые компоненты) + индекс эскалационных сигналов
 → редакционные проверки → очередь → Telegram (или на одобрение в админ-чат)
 → ежедневная сводка · автопоиск новых источников · здоровье источников ·
   рейтинг источников по фактической точности
```

Каждый цикл занимает ~4 минуты и около 20–30 вызовов LLM. По расписанию (приватный репозиторий): полный цикл раз в 3 часа, в остальные часы — быстрые проходы для админ-бота (кнопки ✅/❌ срабатывают в пределах часа).

## Редакционные гарантии (что проверяется автоматически)

- Заявление стороны не превращается в факт: каждое утверждение размечено (FACT, OFFICIAL_CLAIM, OSINT_CLAIM, ASSESSMENT, ANALYSIS, UNCONFIRMED). Если FACT приписан министерству или Кремлю, материал уходит на ручную проверку.
- Перепечатки одного Reuters считаются одним источником: независимость определяется по первоисточнику.
- Старые события, вновь ставшие вирусными (`OLD_RESURFACED`), и дубликаты не публикуются. Дата события хранится отдельно от даты публикации и даты обнаружения.
- Точные координаты, ссылки, выдуманные моделью, и нерусский текст блокируют публикацию.
- Материалы только из соцсетей или с «рискованным» заголовком отправляются на одобрение человеку.
- Повторно публикуется только существенное обновление — ответом на исходный пост.
- Индекс 0–100 показывает интенсивность наблюдаемых индикаторов за 7 дней. Это **не** вероятность войны; контрсигналы его снижают.

## Быстрый старт (локально)

Нужен Node.js 24+ (уже установлен).

```bash
npm install
```

```bash
cp .env.example .env
```

Впиши `GEMINI_API_KEY` в `.env`. Затем:

```bash
npm run cycle
```

```bash
npm run posts -- 10
```

```bash
npm run report
```

`DRY_RUN=true` (по умолчанию) означает, что всё собирается и пишется, но ничего не отправляется. Отчёт `out/report.html` показывает события, причины оценок, проверки, очередь, источники и кандидатов.

## Telegram

1. В @BotFather создай бота (`/newbot`) и получи токен.
2. Создай канал и добавь бота администратором с правом публикации.
3. Напиши боту `/start` в личке. Это будет админ-чат, его id нужен для `TELEGRAM_ADMIN_CHAT_ID`.
4. Пока `PUBLISH_MODE=review`, каждый пост приходит в админ-чат с кнопками ✅/❌ и объяснением оценки.

Команды админ-чата: `/status`, `/pending`, `/approve N`, `/reject N`, `/why N` (почему событие так оценено), `/sources`, `/candidates`, `/promote домен`, `/block домен`, `/mode auto|review`.

## Автономная работа: GitHub Actions (€0)

Workflow `.github/workflows/monitor.yml` запускает полный цикл каждые 3 часа и быстрые проходы в остальные часы (рассчитано на 2000 бесплатных минут приватного репозитория). База SQLite хранится в ветке `state` одним коммитом, который каждый раз перезаписывается, поэтому история не растёт. Там же лежит `report.html`.

- Secrets: `GEMINI_API_KEY`, `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID`, `TELEGRAM_ADMIN_CHAT_ID`.
- Variables: `DRY_RUN` (по умолчанию `true`, поставь `false`, когда будешь готов), `PUBLISH_MODE`, `PUBLISH_THRESHOLD`.
- **Публичный** репозиторий даёт безлимитные минуты Actions. **Приватный** даёт 2000 мин/мес: в этом случае поставь полный цикл раз в 3 часа и убери быстрые проходы (около 1200 мин/мес). В публичном репо база (новости и решения редакции) видна всем; секреты не видны.

## Бесплатные ограничения

| Что | Ограничение | Как обходится |
|---|---|---|
| Gemini free tier | дневные/минутные квоты на модель; бывают 503 при перегрузке | цепочка моделей с автопереключением, пакетный триаж, капы `LLM_MAX_CALLS_*`. Лучше отдельный ключ, а не общий с AI Newsroom |
| Эмбеддинги | ~100 текстов/мин | пакеты по 90 с паузой |
| Reuters/AP/AFP | нет RSS | GDELT + ссылки из статей → оригинал подтягивается автоматически |
| NATO, минобороны Финляндии/Литвы и др. | нет RSS, защита от ботов | HTML-коллектор страниц новостей (Минобороны Финляндии, ВС Швеции, ISW) + запрос GDELT по официальным доменам |
| X (Twitter) | бесплатного API нет | Telegram-каналы через `t.me/s/`, Bluesky |
| GDELT | 1 запрос / 5 с на IP | один запрос за цикл по кругу; сбой не ломает цикл |

## Структура

```
config/sources.yaml     стартовый реестр источников (tier, сторона, надёжность)
src/collectors/         rss, telegram (t.me/s), web (страница новостей), gdelt, bluesky
src/pipeline/           collect → prefilter → triage → cluster → primary → analyze → score
                        → editorial → publish · escalation · digest · discovery · maintenance
src/admin/bot.ts        админ-бот (getUpdates, без сервера)
src/report.ts           HTML-отчёт
tests/                  node --test, без сети
```

Проверка перед коммитом: `npm run check`.
